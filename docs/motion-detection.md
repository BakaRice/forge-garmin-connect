# 摆臂往返次数与频率

2026-10-03 用户确认第一版范围：手动开始运动记录后检测摆臂，完整往返计一次，显示次数和次/分钟，停止后固定汇总，并保存至活动文件。真机验收在功能完成后统一进行。

## 检测规则

`ForgeMotionDetector` 接收三轴角速度（deg/s）和采样间隔。首次明显运动建立本次往返的方向，将后续角速度投影到该方向并积分；去程和回程都满足条件才计数。

- 明显运动阈值：12 deg/s。
- 去程、回程各至少 18°；回程还需达到去程角度的 80%。
- 完整候选持续至少 450ms；回程后安静 120ms，或下一次去程开始时结束当前候选。
- 候选 8 秒超时、采样间隔超过 200ms、缺失角速度或非法间隔会清除未完成候选，已完成次数保留。
- 静止、小幅抖动、单独去程、回程不足不计入次数。

只保存最多 6 个最近完成时刻，不积存原始采样。当前频率按最近完成时刻的间隔换算，至少需要两次完整往返；10 秒无新完成动作后显示缺失，恢复动作后重新积累频率窗口。平均频率为“完整往返次数 ÷ 原生录制分钟数”。

`ForgeMotion` 按设备能力请求最多 50Hz 的同步陀螺仪/加速度批次；API 5.1.1 及以上请求并检查采样时间戳，旧 API 使用名义采样间隔并检查真实回调缺口。加速度只用于采样可用性诊断，角速度用于计次；缺失加速度不阻塞有效角速度的计数。

这些阈值是第一版默认值。模拟数据测试能验证规则和生命周期，真实佩戴的识别准确率仍需真机动作验证和调参。

## 使用方式与保存内容

原有 START / STOP / SAVE 流程保持不变。录制中和停止汇总界面可用 UP/DOWN 在时长心率页与动作页之间切换；动作页录制时显示最近频率，停止后显示全程平均频率。有效静止采样显示次数 0，没有有效采样显示 `--`。

活动文件使用两个 SESSION Developer Fields：ID 0 `Forge Cycles`（UINT32，cycles），ID 1 `Forge Avg Cadence`（FLOAT，cycles/min）。只有拿到有效动作采样后才创建统计字段；采样或统计字段异常应保持原生运动记录、停止和保存可用。Garmin Connect 的实际展示需要同步真机活动后确认。
