# Forge 完整往返摆臂检测

用户已确认：完整往返算一次；第一版包含次数、次/分钟、UP/DOWN 查看、停止汇总、FIT 统计；完成后统一真机验证。

检测模块处理采样数据，不调用 UI 或录制接口。使用角速度方向区分去程与回程，积分估计转动角度，过滤短抖动与不完整回程；加速度用于采样可用性和调试。初始动作方向决定本轮参考轴，允许不同佩戴方向。阈值是待真机校准的初值，模拟数据通过不代表真实动作准确率。

采样模块按设备支持的速率请求最多 50Hz 加速度与角速度，逐批处理，保留有界统计；不长期存储原始样本。只在录制成功后开始采样；确认框期间继续；成功停止或丢弃后取消监听。失败时原有活动录制可继续，次数显示缺失而不是伪造零值。

计次在去程和回程各达到至少 18°、回程达到去程角度的至少 80%，且回程结束后发生；持续往返跨越下一次去程时允许完成前一次。最短动作周期与候选超时限制误计。频率以最近有限次数的完成时间间隔计算，单位次/分钟；停止时另固定本次平均频率（次数 / 录制分钟数）。

保留现有时长和心率页面。在 RECORDING / SUMMARY 中 UP/DOWN 切换到动作统计页，START/STOP/SAVE/BACK 语义不变。顶部完整调试信息继续显示。增加中文次数、频率、传感器状态标签，仍使用原比例位图。

FIT 使用两个 SESSION Developer Fields：往返次数和平均次/分钟；设置展示元数据。字段创建或写入失败不阻断原生活动保存，缺失传感器不输出伪造的零统计。Garmin Connect 的最终展示留给真机同步验收。
